# 四站跨站 SEO 关键词协同策略建议（仅作建议输出）

> 说明：本文件仅针对四座独立站点的内容边界与长远协作输出策略建议；开发 `mofatizi.blog` 期间**未修改**前三个博客的任何源码、仓库或配置文件。

## 1. 四站核心定位分工

| 站点域名 | 站点名称 | 主攻搜索意图与核心词簇 | 内容切入差异 |
| --- | --- | --- | --- |
| `jichangyouhui.blog` | 机场优惠 | 机场优惠码、折扣活动、折后价格计算 | 专注活动规则、可验证折扣率与用码实付核算 |
| `jichang-wending.blog` | 机场稳定 | 稳定机场选择、长期使用场景分析 | 专注工作/学习/团队长期连续性、服务特点与多期分析 |
| `jichang-pianyi.blog` | 机场便宜 | 便宜机场推荐、10元/20元预算、每GB单价 | 专注预算档位榜、年付小包/不限时流量包单价横评 |
| `mofatizi.blog` | 魔法梯子 | 梯子推荐、Clash 教程、十大客户端百科、网络工具入门 | 专注软件生态、协议/TUN/DNS 知识与客户端兼容性筛查 |

## 2. 重点重叠风险区与建议应对方案

1. **「稳定梯子推荐」与「稳定机场推荐」（mofatizi vs jichang-wending）：**
   - `mofatizi.blog` 的 `/recommend/reliable/` 已限定从「线路传输机制（BGP/IEPL/IPLC）、客户端进程稳定与主备方案架构」入手；建议 `jichang-wending.blog` 继续深耕特定人群长期订阅经验与月/季/年维稳选型，避免两者出现相同品牌文案。
2. **「便宜梯子推荐」与「便宜机场推荐」（mofatizi vs jichang-pianyi）：**
   - `mofatizi.blog` 的 `/recommend/budget/` 已限定比较「软件自身成本（免费开源 vs 付费小火箭 vs 官方客户端）、工具形态与月付试错门槛」，未复制 `jichang-pianyi.blog` 的预算榜单与每 GB 排名表。
3. **「优惠码信息」展示原则：**
   - `mofatizi.blog` 不设立独立的 `/coupons/` 优惠码汇总频道，优惠码仅作为 `/brands/[slug]/` 品牌档案页面中的购前辅助字段展示，确保优惠词主权重保留在 `jichangyouhui.blog`。
4. **互链克制：**
   - 四个站点保持完全独立部署与独立导航，不建设用于操纵搜索引擎排名的全站底部交叉互链网络（Link Wheel）。
