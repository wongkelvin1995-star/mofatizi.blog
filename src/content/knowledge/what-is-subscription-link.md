**核心结论：** **订阅链接（Subscription Link）** 是一条由代理服务商为你的个人账号生成的专属配置同步网址（API 接口）。当你将其导入支持第三方导入的客户端时，软件可以通过这条网址自动下载并更新最新的服务器节点列表与路由规则，免去手工逐条录入服务器 IP、端口和密码的繁琐操作。

## 1. 为什么现代代理工具都要用订阅链接？

在早期代理时代，每增加或更换一台服务器，用户都要手动复制 IP、端口、加密密码，一旦机场因为线路维护或域名更新调整了服务器地址，所有用户的旧节点就会集体失联。

订阅机制出现后，客户端只需记住这**唯一一条静态 URL**：
- **批量下发节点与规则：** 一次更新就能把几十个地区节点及内置国内外分流规则同步到本地；
- **动态无感维护：** 服务商更新中转入口后，用户只需在客户端点一次「更新订阅」（或开启自动更新），配置即自动刷新；
- **同步套餐计量信息：** 客户端可以通过解析服务器返回的 HTTP 响应头，直接展示当前套餐已用 GB、总流量和到期日。

## 2. 千万分清：三种截然不同的网址

新手排查报错时，80% 的「无法导入」都来自把这三类网址张冠李戴：

1. **品牌官网 / AFF 注册购买链接：** 用于在 Chrome / Safari 浏览器里打开注册账号、下单付款和登录用户中心。**不能填进客户端订阅框！**
2. **订阅链接（Subscription URL）：** 登录用户中心后，在面板「一键导入 / 复制订阅」里获取的带随机长字符串 `token` 的接口链接。**专门用来填进 Clash / Shadowrocket / v2rayN。**
3. **官方客户端专属登录：** 部分品牌（如光速云、飞猫云、唯兔云、灵猫、闪跃、无忧链接新订单等）直接采用账号密码在官方客户端登录，**后台根本不生成通用的第三方订阅链接**。

## 3. 订阅链接的安全属性：等同于你的流量密码

请记住一条基本安全规则：**任何拿到你完整订阅链接的人，都不需要知道你的机场登录密码，就能直接把你套餐里的所有节点拉取到他自己的设备上使用。**

因此日常必须做到：
- 切勿把订阅地址直接发布在群聊、社区提问帖或公开的代码仓库截图里；
- 若在论坛请求排查 YAML 语法问题，先删掉 URL 里的 `token=` 部分再发文字；
- 一旦怀疑地址外泄或发现后台流量莫名下降，第一时间去用户中心点击 **「重置订阅链接」** 让旧链接作废。详情参见 [订阅链接泄露风险与应急处理](/knowledge/subscription-leak-risks/)。
