**核心结论：** 灵动云默认主推**官方专属客户端（Windows / macOS / Android）**与 **iOS Nextin（识别码 `LDY`）**；只有满足较高消费门槛（如 2026-11-24 客服口径所述的 **订单金额达 ¥200 或以上**，旧规则对应破晓/凌霄档位）的用户，才可联系在线客服个案申请第三方 Clash/Shadowrocket 订阅。

## 1. 四大操作系统官方接入路径

根据灵动云 2026-11-24 资料档案整理，默认官方客户端路线覆盖以下设备：

| 平台 | 客户端方案 | 获取与登录注意 |
| --- | --- | --- |
| Windows | 官方灵动云客户端 | 注册登录后从官网用户中心下载，账号密码直接登录 |
| macOS | 官方灵动云客户端 | 通过用户中心下载页面获取，避免从非官方网盘接收 |
| Android | 官方 Android APK | 官网下载中心提供正版 APK，建议勿装第三方来源包 |
| iOS / iPadOS | **Nextin**（识别码 `LDY`） | 需按客服指引通过外区 App Store 获取 Nextin 后输入识别码 `LDY` 登录 |
| Linux / 路由器 | 未获明确官方支持记录 | 公开档案未提供官方 Linux 包或路由器公开授权，不建议当作默认可用 |

## 2. 第三方 Clash / Shadowrocket 订阅政策演变与申请规则

很多用户搜索「灵动云支持 Clash 吗」时会看到互相矛盾的旧文章，原因在于灵动云的第三方订阅政策在 2026 年经历了明确调整：
- **早期历史口径：** 曾允许指定高阶套餐（如 `灵动·破晓` 700GB/月、`灵动·凌霄` 1500GB/月）联系客服领取第三方订阅。
- **2026-11-24 客服最新口径：** 调整为**订单金额达到 ¥200 或以上**才可向在线客服（Crisp 或「我的工单」）申请特殊优先订阅服务，且属于人工审核发放而非自动出现在网页后台按钮中。
- **核心提醒：** 若你选购的是月付 ¥20 的拂风、月付 ¥50 的驭浪或 ¥99/年的穿云包，不应预设能直接拿到 Clash YAML 订阅链接；如果必须使用 [Clash Verge Rev](/clients/clash-verge-rev/) 或路由器 [OpenClash](/clients/openclash/)，务必在付款前向灵动云 Crisp 在线客服书面确认当前订单是否符合发放资格。

## 3. 安全与登录环境特别提示

灵动云公开资料中记录了两条特有的使用限制：
1. **校园网支持边界：** 客服曾明确说明不为校园网环境提供使用支持，高校用户需留意这一前提；
2. **公共 Wi-Fi 防护：** 安全防护期间曾提示暂停部分公网登录环境并建议切换手机热点重试。日常登录用户中心或刷新客户端时如遇阻拦，切勿在非官网渠道寻找「破解入口」，可通过正常移动网络环境联系 Crisp 客服处理。
